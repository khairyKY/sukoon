Brand identity · exploration 01

Sukoon — three directions

سكون — calm, stillness. A continuous companion that turns a live glucose number into a feeling you can trust. Heritage informs the feel, not the letterforms. Each direction is a color + type system, shown doing the app's real job: an adaptive light/dark readout, in mg/dL, for a Gulf-first audience.

08 The complete screen set · every remaining flow, bilingual (EN · عربي)

Everything the app still needed — onboarding, all Home states, graph, logbook, insights, alarms, sharing, sensor, settings and system surfaces — each shown as an English / Egyptian-Arabic pair, in the Still system. Numerals switch to Arabic-Indic and the layout mirrors right-to-left on the عربي side.
